# Ferramentas de Cyber Security — TryHackMe

## Análise de Malware e Arquivos

### VirusTotal
- **Site:** https://www.virustotal.com
- **O que faz:** Analisa arquivos, URLs e hashes usando dezenas de antivírus ao mesmo tempo.
- **Quando usar:** Você recebeu um arquivo suspeito e quer saber se é malware.

## Busca de Dispositivos e Infraestrutura

### Shodan
- **Site:** https://www.shodan.io
- **O que faz:** Motor de busca para dispositivos conectados à internet (servidores, câmeras, roteadores, IoT).
- **Quando usar:** Quero saber quais dispositivos de um tipo estão expostos na internet.

### Censys
- **Site:** https://search.censys.io
- **O que faz:** Parecido com o Shodan, mas focado em domínios, certificados e portas abertas.
- **Quando usar:** Auditoria de ativos e análise de certificados SSL.

## Vulnerabilidades

### CVE (Common Vulnerabilities and Exposures)
- **Site:** https://cve.mitre.org
- **O que faz:** Lista padronizada de vulnerabilidades conhecidas. Cada falha tem um ID único (ex: CVE-2014-0160).
- **Quem mantém:** MITRE Corporation.

### NVD (National Vulnerability Database)
- **Site:** https://nvd.nist.gov
- **O que faz:** Banco de dados do governo americano com dados enriquecidos sobre CVEs, incluindo nota de gravidade (CVSS).

### Exploit Database (ExploitDB)
- **Site:** https://www.exploit-db.com
- **O que faz:** Repositório de códigos de exploit verificados para vulnerabilidades conhecidas.
- **Atenção:** Usar exploits só em ambientes autorizados.
